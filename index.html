    Working…

    1. Drag a box over the inside of the plot, just inside the axes, leaving out the axis lines and tick marks. Drag an edge or corner to adjust it. The axes are then found along the box's bottom and left edges.

    2. Tick marks are found along the crop's bottom and left edges (shown in blue), and points are placed on the outermost ones. Type the value printed at each point's tick, or click another tick to move the selected point. For X points only the horizontal position is used; for Y points only the vertical. Drag a marker to adjust it.

      X axis
      Y axis

      Scale bar: place X1 / Y1 on a reference whose value you know (usually the 0 line) and type that value, then click both ends of the bar and type its length. Values increase to the right and upward.

    3. Click the data series inside the crop to pick its color. Pick more than one if the line has several shades. Unmatched pixels are faded in the preview.

        Saved datasets drawn over the original image (no edits, with any editor crop applied). The axis values and the units you recorded are shown outside the image. Scroll to zoom and drag to pan.

        Before you start

        • Use each figure at its original resolution. Don't shrink, compress or re-screenshot it.
        • The dataset you want must be a single color that nothing else in the plot uses. If curves overlap, recolor the one you want in an image editor first.
        • Erase legends, labels and annotations inside the plot area before opening the image.
